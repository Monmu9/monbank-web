MONBANK – Banca Simulada

MONBANK es una aplicación web de banca simulada desarrollada con HTML, CSS y JavaScript. 
Permite visualizar el saldo, registrar movimientos financieros, simular transferencias, enviar consultas y ver gráficos de evolución del saldo. 
Todo ello ha sido realizado con integración en Firebase y una interfaz moderna con modo oscuro.

## Funcionalidades principales

- ✅ Inicio de sesión simulado
- 💰 Visualización de saldo actual
- 📈 Gráfico interactivo de evolución del saldo (Chart.js)
- 🔄 Registro de ingresos y gastos
- 📋 Historial de movimientos con opción de eliminar
- 📬 Formulario de contacto con almacenamiento en Firebase
- 🌙 Modo oscuro con persistencia local
- 🔒 Gestión de sesión con `localStorage`

- Firebase Firestore (base de datos en tiempo real)
- Chart.js (gráficos dinámicos)
- Font Awesome (iconos)
- Google Fonts (tipografía Roboto)
