MONBANK – Banca Simulada

MONBANK es una aplicación web de banca simulada desarrollada con HTML5, CSS3 y JavaScript vanilla. 
Permite visualizar el saldo, registrar movimientos financieros, simular transferencias, enviar consultas y ver gráficos de evolución del saldo. La web simulada cuenta con una interfaz moderna con modo oscuro. 
Todo ello ha sido realizado con para demostración de habilidades front-end en portfolio profesional.

## Funcionalidades principales

- ✅ Inicio de sesión simulado
- 💰 Visualización de saldo actual
- 📈 Gráfico interactivo de evolución del saldo (Chart.js)
- 🔄 Registro de ingresos y gastos
- 📋 Historial de movimientos con opción de eliminar
- 📬 Formulario de contacto con almacenamiento en Firebase
- 🌙 Modo oscuro con persistencia local
- 🔒 Gestión de sesión con `localStorage`
